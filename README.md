# IT1214-Student-Grade-System

**Project Purpose**
This is a Java console-based application developed using Object-Oriented Programming (OOP). It helps teachers manage student records digitally by allowing them to add students, view records, search by student ID, and calculate average marks.

**Features**

1.Add a student record

2.Display all student records

3.Search for a student by ID

4.Calculate and display average marks



##How to Run the Program

**Compile the program with CMD**

    javac Main.java
  
  **Run the program**
  
    java Main;




**Example Menu**

=== Student Grade Management System ===
1. Add a Student
2. Display All Students
3. Search for a Student by ID
4. Calculate and Display Average Mark
5. Exit
